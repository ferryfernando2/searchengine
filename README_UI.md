## 🎮 How to Use

### Toggle Theme
Click the theme button in the top-right corner to switch between light and dark modes.

### Search
1. Type your query in the search box
2. Press Enter or click the search button 🔍
3. Results appear with smooth animation
4. Hover over results to see the lift effect

### Language Filter
Click the language flag (🌐) to cycle through:
- 🌐 Auto (all languages)
- 🇺🇸 English only
- 🇮🇩 Indonesian only
